## 첫 영상 만들기

VideoWeb 무료 페이지는 5초·480p와 16:9, 9:16, 1:1을 안내합니다. 텍스트만 사용할 때는 이미지 칸을 비우고, 이미지로 유도할 때는 시작·종료 이미지 두 장을 준비하세요. 동작 하나와 카메라 움직임 하나에 집중하고 필요한 인증 후 한 번 제출하세요. 영상과 소리를 확인한 뒤 파일을 저장하세요.

## 영상과 프롬프트로 배우기

X 사례는 기존 6개에 9개를 더한 15개입니다. 게시물과 영상 정보를 다시 읽었으며 작성자의 전체 프롬프트와 영상으로 연결되는 링크 및 영어·중국어 설명을 제공합니다. 이전 프레임 검토는 출처를 표시하며 재생성하지 않았습니다.

[15 X videos + prompts](./docs/x-community-showcase.md) · [MiniMax official videos](./docs/official-h3-examples.md)

10~15초 또는 여러 참조를 사용하는 사례도 있습니다. 무료 폼에서 같은 기능을 쓸 수 있다는 뜻은 아닙니다. 모델의 2K 출력과 API도 무료 이용 범위와 별개입니다.
