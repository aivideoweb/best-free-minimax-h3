# Edit the tea trial into a six-second concept ad

[Back to commerce](../README.md#workflow-commerce) · [简体中文](./commerce-three-shots_zh.md)

Start with **one generation, edited into three beats**. This is an untested fictional tea concept. For a real product, read the [reference-image guide](./product-reference.md) first.

## Route A: use one homepage clip

Try the [homepage tea prompt](../README.md#workflow-commerce) in [UGC Maker](https://ugcmaker.org/free-minimax-h3/) at 5s, 16:9. If a result returns, download it and check bottle shape, label and continuous light.

Create a 16:9 project in an editor with trimming and freeze-frame tools. **All three beats use one file, not three new generations.**

| Beat | Source | Timeline | Purpose |
|---|---|---|---|
| Opening | Freeze a frame just before the action for 1 second | 0–1s | Establish the product |
| Action | Trim about 3 seconds of the clearest stable light movement | 1–4s | Reveal texture; if the action needs longer, keep its natural speed and extend the edit |
| Ending | Freeze a stable frame after the action for 2 seconds | 4–6s | Add fictional copy in the blank area, such as “Take tonight slowly” |

Match each freeze frame to the adjacent action frame. Use straight cuts before adding transitions. If trimmed ambience jumps, mute it and lay a continuous cleared ambience track underneath. Check readable copy, accidental scaling changes and audio clicks.

## Route B: generate an establishing shot only if needed

For an observatory opening, make **one additional generation** in the same tool. Keep this prompt separate from the product prompt.

```text
Create one five-second establishing shot, 16:9.
Inside a fictional mountaintop observatory before dawn, an indigo ridge is visible through a round window.
An empty dark desk receives cool blue light from the window.
Locked wide shot; only distant thin clouds move gently. Hold the final second.
No bottle, people or lettering. Faint distant wind only.
```

Use about one second to replace Route A’s opening freeze. Reuse the cool blue light, dark desk and observatory descriptions. If the room or lighting does not match, return to Route A rather than adding more tools. Leaving the product out of this insert avoids product-identity conflicts between generations.

## When to try another tool

Adjust the prompt in the current tool first. For an alternative composition, optionally trial the same prompt and settings in a support entry, then compare usable takes. Switching is not required and never replaces continuity checks.

Export with the source resolution in mind: a larger project frame does not create missing detail. Save the tool, prompt, settings and edits for reuse.
