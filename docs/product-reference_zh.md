# 从创意试拍到自己的商品或角色

[返回场景包](../README_zh.md#workflows) · [English](./product-reference.md)

先决定这次要解决什么问题：**试构图和动作，用文字；需要保留商品外观或角色身份，准备参考图。** 两条路径都需要检查生成结果，参考图也不是精确还原的保证。

## 路径一：先试创意

首页的纯文字练习适合虚构商品、人物和场景。替换颜色、形状和动作，可以试出自己想要的氛围；得到的是概念样片，不能据此认定真实商品已经被准确还原。

先只完成一个镜头。需要多段时，重复使用同一段外观描述，并逐段比较；不要为了凑齐镜头，把明显不同的瓶型、面孔或服装拼在一起。

## 路径二：让镜头围绕已有素材展开

免费表单的图片引导需要**首帧和尾帧两张图**。准备方式：

1. 使用自己拍摄、制作或有权使用的商品或角色图片，确定输出比例。
2. 先做好开场和结束画面。两张图保持同一商品、人物、服装、背景和比例，只改变本镜需要的一个状态，例如灯光位置或手部姿态。
3. 若没有合适的结束画面，先拍摄或制作一张与开场相符的尾帧；不要把两张不同商品的照片硬拼成一对。相同图片是否可以同时作为首尾帧，要看页面是否接受及实际效果。
4. 同时上传两张图，把提示词改成对实际画面的描述，只写两帧之间需要怎样运动。图片槽是起止画面，不是“商品图”和“背景图”两个独立参考槽。

**可改写的提示词模板（需要先替换方括号内容）：**

```text
生成一个 5 秒的 [16:9 / 9:16 / 1:1] 镜头。
以已上传的首帧开场，以尾帧结束。
画面中的 [具体商品或角色] 保持 [轮廓、颜色、服装等固定细节]。
只有 [两张图之间实际变化的状态] 缓慢变化，摄影机 [保持固定或描述单一运动]。
最后一秒稳定停留，声音为 [所需环境声]，不增加其他物体或文字。
```

这是待试拍模板，没有经过生成验证。检查开头、中间和结尾的商品轮廓、标签、颜色、手部、面孔与背景；首尾正确而中间变形的片段也应淘汰。需要精确文字时，在剪辑中叠加核准内容，并检查它是否与画面贴合。

## 要做连续镜头时

优先从同一条可用视频裁剪开场、动作和结尾，减少重新生成带来的变化。确实需要新角度时，再为下一镜准备对应的首尾画面，保持外观与光线，并逐镜比较。

需要固定身份、分开控制商品与环境、参考视频运镜或声音节奏时，先从[进阶示例中文导读](./prompt-library_zh.md)确认所需素材，再按下面的路线继续：

- **先了解输入方式：** 查看[模型能力与输入说明（英文）](./minimax-h3-overview.md)，区分首尾帧和多素材参考。
- **请开发者接入：** 查看[接口流程（英文）](./api-workflow.md)，根据其中的官方文档核对当前接口是否接受示例所需的图片、视频和音频。
- **自行部署：** 查看[中文部署指南](./deployment-guide.md#简体中文部署指南)，先确认模型分支、输入类型和硬件要求，再准备运行环境。

后两条是技术路线，不能视为免费工具页已提供的功能。只有首尾帧两个图片槽的表单，不能直接承接多素材参考示例。
