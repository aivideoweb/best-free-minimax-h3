## 最初の動画を作る

VideoWebの無料ページでは5秒・480p、16:9／9:16／1:1を案内しています。テキストのみなら画像欄を空にし、画像を使う場合は開始と終了の2枚を用意します。1つの動作と1つのカメラ移動に絞り、必要な認証後に1回送信してください。映像と音声を確認し、必要な動画を保存します。
